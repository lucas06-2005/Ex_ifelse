# Exercício If/Else

Neste exercício voltei a pedir ajuda à IA. Ela gerou um código que funcionava, mas não quis ficar por aí. Pensei então num conceito mais original, algo que mostrasse o contraste entre os Açores e Lisboa. Decidi que, do lado esquerdo, haveria a calma dos Açores, com cores relacionadas com o ambiente, e, do lado direito, o caos de Lisboa, com tons mais quentes e agressivos para refletir a agitação da cidade.
